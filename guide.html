전체 진행 단계

쇼핑몰 상황에 따라 일부 단계는 동시에 진행되거나 순서가 바뀔 수 있습니다. 각 단계에서 회신이 필요한 내용은 담당 매니저가 메일로 따로 요청드립니다.

  1. 1

    담당 매니저 배정과 첫 안내

    이전 전담 매니저가 배정되어 전체 진행 방향을 안내드립니다.

    메이크샵이 하는 일

    • 1차 안내 메일 발송 (데이터·디자인·기본 설정·PG 신청 안내)
    • 이전 대상 데이터 범위 확인

    고객님이 준비하실 일

    • 기존 쇼핑몰 관리자 계정 전달
    • 오픈 희망 일정 회신
    • SNS 간편로그인 사용 시 연동 계정 정보 전달
  2. 2

    데이터 검토

    기존 쇼핑몰 데이터를 살펴보고 이전 가능한 항목과 제한되는 항목을 정리합니다. 이 단계에서는 실제 이전을 진행하지 않습니다.

    메이크샵이 하는 일

    • 상품·회원·게시판 데이터 구조 검토
    • 데이터 검토 결과 안내서 전달

    고객님이 준비하실 일

    • 안내서 항목별로 확인 또는 수정 요청 회신
    • 관리자에서 내려받을 수 없는 데이터는 기존 솔루션 고객센터에 백업 요청 (필요 시 안내드립니다)
    네이버 스마트스토어에서 이전하시나요?

    스마트스토어는 상품과 리뷰 데이터만 이전할 수 있습니다.

    상품 — API 관리 메뉴에서 메이크샵 연동을 설정하면 한 번에 이전됩니다(1회 가능). 옵션, 상세설명, 정보고시, 추가 이미지, 추가 상품은 이전되지 않으며, 이전 후 스마트스토어에서 바꾼 상품 정보는 메이크샵에서 직접 수정해 주셔야 합니다.

    리뷰 — 관리자 계정 전달 또는 부관리자 설정 후 검토하며, 비회원 글로 이전됩니다. 실제 이전 범위는 데이터 검토 후 확정됩니다.

  3. 3

    1차 데이터 이전

    회신해 주신 검토 의견을 반영해 데이터를 메이크샵으로 옮깁니다.

    메이크샵이 하는 일

    • 상품·회원·게시판 1차 이전
    • 항목별 이전 결과 안내서 전달

    고객님이 준비하실 일

    • 메이크샵 관리자에서 이전 결과 확인
    • 오픈 일정에 맞춘 최종 이전 일자 협의
    주문 데이터는 최종 이전 때 옮깁니다. 1차 이전 이후에도 기존 쇼핑몰에서 주문이 계속 들어오기 때문에, 오픈 직전 최종 이전 시 함께 처리합니다.
  4. 4

    디자인 세팅

    메이크샵 무료 스킨 200여 종 중 1종을 골라 쇼핑몰 디자인을 세팅합니다.

    메이크샵이 하는 일

    • 보내주신 자료요청서 기준으로 스킨 1차 세팅
    • PC·모바일 미리보기 링크 전달

    고객님이 준비하실 일

    • 스킨 1종 선택 (PC·모바일이 함께 대응되는 반응형 스킨 권장)
    • 디자인 자료요청서 작성 (로고, 배너 이미지 등)
    • 미리보기 확인 후 수정 의견 회신

    무상 세팅 범위와 추가 비용 기준 보기

  5. 5

    기본 설정과 PG 신청

    결제 서비스 심사에는 시간이 걸리므로, 이전 초기에 미리 신청해 두시길 권장합니다.

    메이크샵이 하는 일

    • 설정 항목과 메뉴 위치 안내
    • PG 신청 여부 확인

    고객님이 준비하실 일

    • 임시 판매 상품 3~4개 등록 (PG 심사용)
    • 쇼핑몰 이름, 사업자 인증, CS 정보, 고객센터·계좌 설정
    • 위 설정 완료 후 원하시는 PG사로 신청
    네이버페이(주문형)는 오픈 후에 신청하실 수 있습니다. 그 외 PG와 간편결제는 미리 신청 가능합니다.
    설정 > 결제 설정 > 전자결제(PG) 신청/관리
  6. 6

    운영 정책과 SNS 연동 확인

    기존 쇼핑몰에서 쓰시던 운영 방식을 메이크샵에서도 그대로 이어가도록 맞춥니다.

    메이크샵이 하는 일

    • 배송비, 회원등급, 게시판 권한 등 기존 정책 확인 요청
    • SNS 간편로그인 이전 시 주의사항 안내
    • 추가 개발·커스텀 요청은 영업 담당자에게 전달

    고객님이 준비하실 일

    • 현재 운영 정책 회신
    • 필요한 추가 기능이 있다면 미리 알려주기
  7. 7

    오픈 준비와 최종 데이터 이전

    오픈 일자가 정해지면 최종 데이터를 옮기고 도메인을 연결합니다.

    메이크샵이 하는 일

    • 최종 데이터(주문 포함) 이전
    • 오픈 당일 도메인 연결 세팅

    고객님이 준비하실 일

    • 기존 쇼핑몰 최종 데이터 백업
    • 도메인 네임서버 변경
    • 기존 쇼핑몰에 이전 안내 팝업 게시 (권장)

    오픈 전 체크리스트 열기

  8. 8

    오픈 후 정리

    메이크샵 쇼핑몰이 정상 운영되는 것을 확인한 뒤 기존 쇼핑몰을 정리합니다.

    메이크샵이 하는 일

    • 오픈 후 체크사항과 검색엔진 설정 안내

    고객님이 준비하실 일

    • 기존 쇼핑몰 상품 판매중지
    • 기존 쇼핑몰 주도메인 삭제
    • 검색엔진(SEO) 설정, 네이버페이 등 바로구매 신청

    오픈 후 체크리스트 열기

디자인 지원 범위

스킨을 고르신 뒤 자료요청서를 보내주시면 아래 범위 안에서 무상으로 세팅해 드립니다.

무상으로 세팅해 드립니다

  • 선택하신 무료 스킨 1종 적용
  • 자료요청서 기준 로고·배너·메뉴 구성 반영
  • PC·모바일 미리보기 제공과 1차 시안 검토

추가 비용이 발생할 수 있습니다

  • 스킨 구조를 바꾸는 디자인 튜닝·커스텀
  • 기존 쇼핑몰 디자인 재현 작업
  • 별도 기능 개발

추가 비용은 작업 범위에 따라 달라지며, 요청 내용을 확인한 뒤 영업 담당자가 별도로 안내드립니다.

자주 묻는 질문

전체 이전에 얼마나 걸리나요?

데이터 양, 디자인 세팅 범위, 회신 속도에 따라 달라집니다. 오픈 희망일을 알려주시면 담당 매니저가 그에 맞춰 일정을 안내드립니다.

기존 디자인을 그대로 옮길 수 있나요?

이전 지원은 메이크샵 무료 스킨 200여 종 중 1종을 선택해 세팅하는 방식으로 진행됩니다. 기존 디자인과 비슷하게 맞추는 작업은 범위에 따라 추가 비용이 발생할 수 있습니다.

관리자 계정을 여러 명이 함께 써도 되나요?

메이크샵은 한 아이디로 동시에 접속할 수 없습니다. 담당자별로 부운영자 계정을 만들어 사용해 주세요.
설정 > 운영자 설정 > 운영자 관리

도메인은 언제 연결하나요?

오픈 당일 메이크샵에서 세팅합니다. 그 전까지 도메인 메뉴는 비워두시고, 구매하신 도메인 정보만 미리 공유해 주세요.

오픈 후 검색 노출이 줄어든 것 같아요.
